Master Data Upload

Import permanent NOVARA companies, sites, and contacts for lookup without creating Leads.

Import order

1. Companies   2. Sites   3. Contacts

Use the cleaned final import CSV files. MasterID links the records. CompanyID, SiteID, and ContactID remain the permanent record IDs. Records marked NeedsReview may still be loaded for lookup and corrected later. This tool never creates Leads.

1. Companies

Upload the Companies Import CSV. Each company must have MasterID, CompanyID, and CompanyName. OWNER, MGMT, and OMC - Review are all retained; uncertain relationships are not guessed.

2. Sites

Upload the Sites Import CSV. SiteID and SiteKey are both checked so an existing property is skipped rather than duplicated. CompanyID and MasterID are stored with the site for lookup.

3. Contacts

Upload the Contacts Import CSV. Contacts are stored as permanent NOVARA lookup records linked by MasterID, CompanyID, and SiteID. They are not converted to Leads.
